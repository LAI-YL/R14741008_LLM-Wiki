# raw/ — 原始資料（唯讀）

把你要加入知識庫的資料放在這裡，例如：課堂講義、準則摘要、考試筆記、用 Obsidian Web Clipper 存下的網頁文章。

- 命名：`YYYY-MM-DD-英文-slug.md`（日期 = 加入日期），PDF 等其他格式同理。
- 圖片放在 `raw/assets/`。
- AI 只會讀取這裡的檔案，**不會修改、改名或刪除**。
- 放好之後對 AI 說：「請先讀 AGENTS.md，然後 ingest `raw/檔名`」。

> 目前的 `2026-11-16-us-audit-primer.md` 是建立專案時的起始資料（入門筆記），用來示範 ingest 流程。
