# assets/logos/ — 機構官方標誌（由使用者放入）

請從各機構官網下載官方標誌，依下列檔名存放（SVG 優先，PNG 亦可）：

| 機構 | 檔名 |
|---|---|
| PCAOB | `pcaob.svg` 或 `pcaob.png` |
| AICPA | `aicpa.svg` 或 `aicpa.png` |
| SEC | `sec.svg` 或 `sec.png` |
| GAO | `gao.svg` 或 `gao.png` |

放好後告訴 AI「登記 Logo」，AI 會把它們加進 `assets/index.md`。
商標使用請自行確認各機構的使用規範；AI 不會下載或重新繪製任何 Logo。
