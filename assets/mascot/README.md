# assets/mascot/ — 吉祥物「貓頭鷹審計師」

正式版（依草稿 A「圓滾滾學院派」繪製），一個動作一個檔案，已登記在 `assets/index.md`：

| 檔案 | 動作／表情 |
|---|---|
| `owl-default.svg` | 預設：拿放大鏡 |
| `owl-wave.svg` | 打招呼 |
| `owl-think.svg` | 思考 |
| `owl-point.svg` | 講解（指向右側） |
| `owl-correct.svg` | 答對了 |
| `owl-alert.svg` | 注意／考試陷阱 |
| `owl-read.svg` | 閱讀帳本 |
| `owl-avatar.svg` | 頭像（網站圖示） |

每個動作（頭像除外）另有貼紙版 `owl-*-sticker.svg`：順著輪廓加米白描邊、圓角收邊，給深色背景使用（例如簡報封面）。

`draft-a-round.svg`、`draft-b-suit.svg`、`draft-c-badge.svg` 為選定前的草稿，保留作紀錄，**不可**用於簡報。
新增動作時沿用相同的身形、配色（海軍藍、米白、琥珀）與圓框眼鏡，檔名用 `owl-動作.svg`，並登記到 `assets/index.md`。
