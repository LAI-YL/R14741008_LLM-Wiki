# PCAOB 與 AICPA 審計準則比較

## 問題

美國有兩套主要的財報審計準則，什麼時候用哪一套？它們最常被考的差異是什麼？

## 結論

先看受查者是不是**發行人（issuer）**：是 → [[pcaob-auditing-standards|PCAOB AS]]；不是 → [[aicpa-au-c-standards|AICPA AU-C]]。兩者在報告用語、關鍵事項揭露、內部控制查核三方面差異最大。

## 比較或分析

| 項目 | PCAOB AS | AICPA SAS／AU-C |
|---|---|---|
| 適用對象 | 發行人（上市公司）、證券經紀自營商 | 非發行人（非上市公司、多數非營利組織） |
| 制定機構 | [[pcaob]]（受 [[sec]] 監督） | [[aicpa]] 審計準則委員會（ASB） |
| 法源背景 | [[sarbanes-oxley-act]] | 專業自律 |
| 編號格式 | AS + 四位數（如 AS 2105） | AU-C + 三位數（如 AU-C 320） |
| 無保留意見用語 | Unqualified | Unmodified |
| 關鍵事項 | CAM，強制（[[as-3101]]） | KAM，受委任時才需要（AU-C 701） |
| 內部控制查核 | 與財報查核整合執行（[[as-2201]]） | 非強制 |
| 風險評估 | [[as-2110]] | AU-C 315 |
| 重大性 | AS 2105 | AU-C 320 |
| 舞弊 | AS 2401 | AU-C 240（[[fraud-risk]]） |
| 存貨 | AS 2510 | AU-C 501（[[inventory-and-litigation]]） |
| 函證 | AS 2310 | AU-C 505（[[external-confirmations]]） |
| 期後事項 | AS 2901 | AU-C 560（[[subsequent-events]]） |
| 繼續經營 | AS 2415 | AU-C 570（[[going-concern]]） |
| 標準報告 | [[as-3101]] | [[au-c-700]] |
| 修正式意見 | AS 3105 | AU-C 705 |
| 事務所任期聲明 | 必須 | 不需要 |

> [!exam] 考點
> 題目沒有明說時，從關鍵字判斷：“issuer”、“PCAOB”、“CAM”、“integrated audit” → 上市公司；“nonissuer”、“AU-C”、“KAM” → 非上市公司。
